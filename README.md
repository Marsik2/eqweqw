# XiveVisuals — Fabric 1.21.4 (клиентский мод)

Визуал: космическое небо (4 палитры), звёзды, чёрная дыра, светящиеся частицы.
Плюс удобный HUD и мелкие помощники. Мод ничего не делает за игрока в бою
(нет аима, авто-ударов, увеличенной досягаемости, ESP).

## Управление
- Клавиши: V — палитра, B — частицы, H — HUD, C — приближение (всё меняется в настройках управления)
- /xive — список функций с описанием; /xive <название> — вкл/выкл
- Метки: /xive wp add <имя>, /xive wp del <имя>, /xive wp list
- Настройки сохраняются в config/xivevisuals.properties

## Сборка
JDK 21 + IntelliJ IDEA, открыть папку, Gradle -> build. Jar: build/libs/xivevisuals-1.0.0.jar
Нужны Fabric Loader 0.16.10+ и Fabric API 0.119.4+1.21.4.

## Важно
Авто-спринт и приближение меняют ввод/обзор на вашем клиенте. Правила серверов разные,
гарантировать отсутствие бана нельзя — проверьте правила FunTime перед игрой.

## Сборка без компьютера (GitHub Actions)
1. Создайте репозиторий на github.com и загрузите в него все файлы проекта (включая папку .github).
2. Вкладка Actions -> Build mod -> дождитесь зелёной галочки.
3. Откройте запуск -> Artifacts -> xivevisuals-jar -> скачайте jar.
